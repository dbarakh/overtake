# Overtake

Аркада про обгоны на российских трассах: одна кнопка, держишь — выходишь на встречку, отпускаешь — возвращаешься в свою полосу. 17 этапов, 85 уровней, от Алтая до Владивостока.

Играть: https://dbarakh.github.io/overtake/

Управление: удерживай экран, пробел или левую кнопку мыши.
